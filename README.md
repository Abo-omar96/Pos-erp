# دفتر — برنامج حسابات ويب

واجهة عربية تعمل على الويب وتستخدم Firebase Authentication وCloud Firestore لمشاركة بيانات المنشأة بين الأجهزة. لا تُضمّن بيانات ملف Excel المرفق؛ ابدأ بإضافة بيانات منشأتك من داخل التطبيق.

## التجهيز

1. أنشئ مشروعًا في [Firebase Console](https://console.firebase.google.com/) وأضف تطبيق Web.
2. فعّل **Authentication → Email/Password** وأنشئ حسابات المستخدمين من لوحة Firebase.
3. أنشئ قاعدة **Cloud Firestore**، ثم انشر محتوى `firestore.rules` من تبويب Rules.
4. ضع قيم تطبيق الويب في كائن `firebaseConfig` المصدّر داخل `firebase-config.js`. انسخ قيم الإعداد فقط (`apiKey`, `authDomain`, `projectId`, `appId` وغيرها عند الحاجة)، ولا تلصق مقاطع `import` أو `initializeApp` أو `getAnalytics`؛ يتولى `app.js` تحميل Firebase وتهيئته.
5. أنشئ مستندًا في مجموعة `authorizedUsers`، واجعل معرّف المستند هو **UID** للمستخدم المسموح له. لا يستطيع المستخدم إضافة نفسه إلى القائمة؛ أضف كل مستخدم يدويًا من لوحة Firebase.
6. شغّل الملفات عبر خادم ويب محلي (مثل إضافة Live Server في VS Code)، ثم افتح عنوان الخادم. لا تفتح `index.html` مباشرة باستخدام `file://`.

قواعد Firestore تسمح بالقراءة والكتابة فقط للمستخدمين المسجلين الذين لهم مستند في `authorizedUsers`. كل مستخدم مُعتمد يستطيع العمل على بيانات المنشأة المشتركة، لذلك أضف الحسابات الموثوقة فقط.

## الوحدات

الرئيسية، المبيعات والمشتريات، الأصناف والمخزون، العملاء والموردون، سندات القبض والصرف، المصروفات، حركات المخزون، التقارير، وإعدادات المنشأة. الفواتير والسندات تُحفظ كعمليات مترابطة داخل Firestore، ومعدل ضريبة القيمة المضافة الافتراضي 15% ويمكن تغييره من الإعدادات.

هذه نسخة أولية لإدارة العمليات الأساسية وليست بديلًا عن مراجعة محاسب أو اعتماد الربط الرسمي لمنظومة الفوترة الإلكترونية السعودية. اختبرها ببيانات تجريبية قبل استخدامها في حسابات فعلية.
